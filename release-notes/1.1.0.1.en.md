# Mindustry Ark 1.1.0.1 — release notes

## Overview

The embedded game is updated to upstream **Mindustry `v8 Build 160.5`**.

From this version on, **the game binary shipped in this package is the unmodified upstream
release** — byte for byte the file Anuken publishes. The adaptation code the launcher needs has
been moved out into a patch of its own, which loads ahead of the game.

---

## Changed

| Item | Notes |
|---|---|
| **Embedded game** | `160.4` → `160.5` |
| **The game binary** | Now the upstream release, **modified in no way** |
| **The adaptation code** | Moved out of the game binary into a patch of its own |

This version has **no functional changes of this project's own** — everything under "Fixed"
below is upstream `160.5`.

---

## Fixed

These are **fixes in upstream `160.5`** (not made by this project); the ones a player is likely
to notice. The full list is on the
[upstream release page](https://github.com/Anuken/Mindustry/releases/tag/v160.5).

| Problem | Notes |
|---|---|
| **Entities with extremely large hitboxes freezing a thread** | Shows up as a stall or an unresponsive game |
| **Map descriptions not wrapping** | Long descriptions crammed onto one line |
| **Logic processors** | Hex / binary values above `Long.MAX_VALUE` would not parse; the graphics and text buffers did not clear on restart; the shape text marker could not be selected in the logic UI |
| **Crafters lagging when their output is boosted** | They could not output fast enough |
| **Target dummies** | Would not land when other dummies with large hitboxes were nearby |
| **Data patches** | Blocks with 0 liquid capacity no longer draw liquid bars; images now get alpha bleeding and antialiasing, matching how vanilla sprites are processed |
| **Servers / mods** | Certain popups still showed on servers while the UI was hidden; the mod browser now prioritises mod releases whose title matches the current game version |

## Installing

**An unsigned HAP cannot be installed directly.**

**Option 1 — an installer tool (no dev environment needed, recommended)**

| Tool | Notes |
|---|---|
| [小白调试助手](https://github.com/likuai2010/auto-installer/releases/latest) | Free cross-platform HarmonyOS debug tool; signs and installs in one step |
| [HoKit](https://github.com/yabi-zzh/HoKit/releases/latest) | One-click re-signing, screen mirroring, performance monitoring, file management |

**Option 2 — sign it yourself with DevEco Studio**

1. Open this project in DevEco Studio
2. `File → Project Structure → Signing Configs → Automatically generate signature`
3. `bash deploy.sh`

More detailed installation notes are in the [README](https://github.com/haohandc/MindustryArk/blob/master/README.en.md).

## Supported devices and limitations

**By device**

| Device | Self-signed install | App store |
|---|---|---|
| **Tablet** | Works | Works (pending AppTest) |
| **Phone** | Partly (see below) | **Not offered** |
| **PC · 2in1** | Untested | Untested |

- **Why there is no store build for phones**: the executable-memory permission (the ACL
  `ALLOW_WRITABLE_CODE_MEMORY`) is **only open to tablets and PC / 2in1**, and Java's JIT needs it.
- **Why phones are "partly"**: it depends on the system version, see below. On a version that
  qualifies, a self-signed install behaves the same as on a tablet.

**By system version**

- The minimum version this app declares is **6.1.1 (API 24)**. That floor is **untested**.
- **From API 26 (HarmonyOS 7)**: a debug install **requests the supported ACL permissions
  automatically**, so a self-signed install works on phones.
- **HarmonyOS 5 / 6**: that mechanism does not exist. Whether a self-signed install works there
  **has to be judged on the device**.

**Other**

- **No achievements, and no Workshop** — both are Steam-platform features; Mindustry itself has neither.
- **arm64-v8a real devices only**; the **emulator will not work** (x86_64 cannot run this package).
- The full list is in [docs/LIMITATIONS.md](https://github.com/haohandc/MindustryArk/blob/master/docs/LIMITATIONS.md).

## About the app store

**This app is not on any app store yet**; GitHub is the only distribution. The plan is a
store listing **overseas**; a mainland listing is not possible because of the **licence number
requirement**.

The **AppTest** submission is the previous version, `1.0.0.2`. The store versions are
**for HarmonyOS tablets and PC/2in1 only, not phones** — for the reason under "Supported devices
and limitations" above.

Distribution on GitHub is unchanged.
